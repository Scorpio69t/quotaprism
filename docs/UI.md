# UI / UX 设计系统

> 当前实现为英文 Demo 总览及托盘面板，主题跟随系统。语言切换、手动主题、完整状态及无障碍/DPI 矩阵仍属 QP-004；以下为目标规范，不代表全部已完成。

## 产品语言
Raycast 式快捷、Linear 式克制；不要做成传统管理后台。深色默认跟随系统，可手动切换。使用中性色底、品牌色点缀、精确数字与清晰状态。统一圆角、间距、字体，避免所有卡片都加粗阴影、炫光或大渐变。Logo 概念为光束进入棱镜后分出多个配额轨道；商标和名称最终核查后再定稿。

## 窗口与布局
- Tray popover：建议 400 × 580 logical px，自适应内容与屏幕可用高度，允许滚动；贴近托盘、自动向可用区域翻转；默认失焦关闭，可固定；键盘 Esc 关闭。Windows 使用 icon + tooltip，macOS 可选短文字。不可假定 Windows 支持菜单栏多行数值。托盘图标按用户选定账户状态生成，未知使用中性图标。
- Dashboard：初始 1080 × 760，最小约 800 × 600 logical px；可缩放；侧栏/内容/设置，不复制网页导航。主窗口关闭隐藏，退出菜单才结束；设置允许改变行为。
- 设置：常规、账户、显示、通知、数据与隐私、关于；未来模块由功能开关显示，MVP 不放无法点击的 Gateway/Agent 菜单。

## 卡片与状态
ProviderCard 只接收 DTO，不调用网络；QuotaMeter 根据真实分母/百分比显示，未知为 `—`。多个限制窗口用独立行、可展开模型/共享池信息。余额无百分比用金额与币种。鲜度标签必须保留，失败显示缓存 + 错因 + 用户可行动项。Demo 全局显著标记。部分刷新保持旧卡片并显示 spinner，不让整个窗口重排。过期与低额度使用不同图标。

## Dashboard 结构
总览：账户数、低额度数、更新时间；按 Provider/别名过滤；卡片支持键盘与排序。详情：全部窗口、来源、认证方式、更新时间、刷新诊断。P1 历史：同一窗口趋势、重置事件、订阅利用率与费用；禁止跨不同单位加总。没有真实可比 token 数据就不画总 token。预测展示假设、范围和不足数据。

## 状态与可访问性验收
空态有“添加账户”和“体验 Demo”；错误说明可执行动作；键盘焦点顺序、焦点环、aria-label、屏幕阅读器语义、可缩放文字；目标 WCAG AA 对比度。中英文长文本不可截断关键数值。测试 100/125/150/200% DPI、双显示器、不同任务栏方向、macOS 刘海与外接屏、暗色/浅色、休眠、失焦。原生托盘的定位与窗口行为以实际平台测试为准。
