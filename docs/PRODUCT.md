# 产品定义与长期愿景

状态：设计基线（2026-11-26），尚未实现。品牌：QuotaPrism / 额度棱镜；Slogan: Every token counts. CLI 候选 qprism（未来）。

## 目标与用户
个人 AI 开发者、购买多个 Coding Plan 的工程师、本地工具爱好者。核心场景：开始 Coding 前看额度，开发途中察觉不足，重置时恢复，续费前回顾利用率。默认无需账号或中心服务；供应商登录仍按各自正规流程。

| CodexBar | 菜单栏、采集适配、状态表达 | 国内 Plan、多平台一致体验 |

公开资料调研，不代表逐一安装实测，不宣称功能独有。链接见 REFERENCES。优先做更可靠的数据模型、极佳托盘体验、中文生态和隐私可控。

## 模块原则
Monitor = 观测；Switch = 改配置；Gateway = 请求转发；Router = 选择目标；Agent = 有工具、有状态、有权限的执行循环。每项分别启用和授权。Monitor 断开未来模块仍能独立工作。任何订阅不能因为可观测就推定可转发。路由不能凭百分比跨不兼容模型随意替换。

## 非目标（MVP）
云同步、团队 SaaS、账号池销售、通用代理、自动修改 CLI 配置、浏览器自动化采集、自动付费、完整 Agent、复杂插件动态加载、移动端、Linux 正式支持。第一版不以功能数量竞争。

## 成功指标（目标，不是已测数据）
- 新用户无需凭据即可体验 Demo；有受支持账号时从安装到首次查询 <= 3 分钟（不含厂商登录）。
- 托盘打开 p95 <= 300 ms（热启动，本地缓存，不等网络）。
- 刷新成功率按供应商和错误类别记录；通过本地测试报告评估，不上传遥测。
- 100% 快照携带来源与观察时间；100% 失败不会伪装成零额度。
- 真实凭据不写入数据库和日志；无用户授权的生成模型请求为零。
