# ADR-0002：M0 离线 Demo 契约与桌面边界

- 状态：Accepted（开发预览；macOS 尚未实测）
- 日期：2026-11-26

## 背景

M0 需要真实桌面窗口和托盘从同一数据契约读取无需凭据的演示数据，同时不提前引入数据库、HTTP 客户端或未来模块。

## 决策

- `prism-core` 定义目前使用的快照、额度窗口、余额、公开错误和 Provider trait；不依赖 Tauri。`prism-providers` 提供纯内存 Demo，不访问网络或读取凭据。当前同步 trait 仅服务离线 Demo；接入真实异步 Provider 前重新设计超时、取消和认证上下文。
- Rust 类型通过 `ts-rs` 生成前端 DTO；测试比较生成内容，变更契约后执行 `cargo run -p prism-core --example export_types`。计数和金额通过字符串传输，未知用 `null`，时间使用 UTC，显示时转本地时间。独立窗口、下一次恢复与重置、余额和百分比分别表达，不跨单位汇总。
- 每个额度窗口分别提供已用值、剩余值及其百分比；可由同一数值和已知上限计算对应百分比，但不能从另一侧推断未知值。余额不转换为百分比。
- 后端持有同一份内存快照；刷新先生成新快照，再通知两个本地窗口读取。Tauri 单实例插件防止重复托盘；窗口关闭隐藏，托盘菜单退出。托盘定位根据当前屏幕工作区和点击位置计算，自动限制面板大小。
- 仅开放本地窗口需要的事件权限和显式应用命令；不增加前端 shell、文件、HTTP 或凭据权限。内联样式仅用于额度条宽度，CSP 不允许远程脚本。

## 后果与限制

当前 DTO 是 M0 展示子集，不是完整 Provider SDK：账户 UUID、认证能力、快照版本、细粒度错误与鲜度、持久化和真实刷新仍待 M1 扩充。Demo 每次刷新重新生成模拟观察时间，不代表供应商规则。托盘定位、DPI 和多显示器需要更多目标平台实测。生成类型仍需在代码评审中检查语义，不能代替运行时输入校验。
