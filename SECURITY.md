# Security policy

This project is in pre-alpha design; no released version is currently supported. For vulnerabilities, use GitHub private vulnerability reporting if enabled, or contact the repository maintainer privately. Do not post secrets, exploit details or account data in public issues. Provide a minimal sanitized reproduction, affected commit/version, platform and impact. No security contact address or response-time guarantee has been established yet.

See [security design](docs/SECURITY-DESIGN.md). Never share live credentials with maintainers or CI. If a credential is exposed, revoke/rotate it at the provider immediately. The project does not offer account sharing, resale, bypassing access controls or unauthorized inference relay.
